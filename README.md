## 📋 Overview

Akbar Dawakhana EHR is a professional-grade electronic health records management system built with modern Python technologies. It provides a complete solution for patient management, prescription generation, billing, and medical record keeping.

## ✨ Key Features

### 🎯 Core Functionality
- **Patient Management** - Complete patient registration and profile management
- **Digital Prescriptions** - Professional prescription generation with PDF export
- **Visit Records** - Comprehensive visit documentation and history tracking
- **Billing System** - Integrated billing and revenue tracking
- **Appointment Scheduling** - Calendar-based appointment management
- **Medicine Database** - Built-in medication library with dosage guidelines

### 🚀 Advanced Features
- **🖨️ Smart Printing** - Direct printer support with automatic PDF fallback
- **📷 QR Code System** - Generate and scan QR codes for instant patient lookup
  - Webcam scanning
  - Image upload scanning
  - Screen capture scanning
- **🌐 Multi-Language** - Full English and Urdu (اردو) support with RTL text
- **💾 Auto Backup** - Automated database backup system
- **📊 Analytics Dashboard** - Real-time statistics and insights
- **🎨 Modern UI** - Clean, responsive interface with dark/light modes
- **🔐 Secure Activation** - License-based activation system

### 📈 Reports & Analytics
- Daily/weekly/monthly patient reports
- Revenue analysis and tracking
- Visit trends and statistics
- Common diagnoses tracking
- Medication usage analytics
